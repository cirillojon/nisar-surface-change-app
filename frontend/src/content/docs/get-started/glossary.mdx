| Term | Meaning |
| --- | --- |
| **Ascending / descending** | Pass heading north / south. Not compared directly |
| **Backscatter** | Radar brightness, in dB |
| **Coherence** | How alike two passes are, 0–1 |
| **dB** | Log scale. +3 dB ≈ twice as bright |
| **Double bounce** | Pulse off water then a stem or wall, back to the radar. Very bright in HH |
| **Frame / track** | Tile / orbit lane. Same frame and track = same geometry |
| **Granule** | One HDF5 file from one pass |
| **HH, HV** | Transmit / receive polarization (H horizontal, V vertical) |
| **InSAR** | Measuring motion from the phase difference between passes |
| **L-band** | ~24 cm wavelength |
| **Line of sight** | Along the radar's slanted view. + toward, − away |
| **Moment** | A stat over a stretch of passes, computed from the NISAR values |
| **Open water %** | Share of pixels with HH below −18 dB |
| **Pass** | One date NISAR imaged a place |
| **Provisional / validated** | Released before / after calibration is final |
| **Reference point** | The spot motion is measured against |
| **Speckle** | Grainy noise in radar images |
