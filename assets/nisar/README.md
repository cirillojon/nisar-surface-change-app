# Source record for the retired NISAR 3D model

Earlier versions of the app displayed a spacecraft model adapted from [NASA Eyes on the Earth](https://go.nasa.gov/eyesonnisar), courtesy of NASA/JPL-Caltech. The [source manifest](nasa-source-manifest.json) records the original geometry and textures, their URLs, and hashes.

AI-assisted Blender and optimization scripts retained the source proportions, removed a helper cube and a duplicate reflector surface, changed the reflector frame to a dark composite material, and simplified three bus and instrument meshes for the compact web export.

The current hero uses radar pass imagery. The Blender model, web exports, and rendered poster have been removed from the current source tree.
